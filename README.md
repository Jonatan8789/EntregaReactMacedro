# E-commerce React – Macedro

Proyecto de e-commerce desarrollado con React como Single Page Application.

## Tecnologías
- React + Vite
- React Router DOM
- Context API
- Firebase Firestore

## Funcionalidades
- Listado de productos desde Firestore
- Vista detalle de producto
- Carrito de compras con estado global
- Checkout y generación de orden
- Navegación SPA
